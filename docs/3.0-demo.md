# Apex Resolve 3.0 demo checkpoint

Use two verified Firebase accounts in the same workspace. Open the dashboard and choose Communication. Enter an issue room and exchange a message describing a problem. Choose Create issue beneath the message, edit the draft, and confirm. Follow Open source message from the new issue. For a long conversation, load earlier history if the source message is outside the latest page.

Return to the original conversation to run AI investigation with consent. Review a suggested task before approving it. Complete the work, attach evidence, request verification, and have an authorized reviewer approve or reject it. Open Resolution to inspect the updated counts.

Explorer, Communication, and Resolution use the same issue permissions. Preferences are saved in Supabase Auth user metadata. New users receive a welcome screen on first data-session creation. Existing users default to Explorer until they choose a preference.

The mode views and message drafts passed compilation. Signed-in browser acceptance of these additions, AI output for a real issue, evidence completeness assessment, and the full two-account demo remain pending. Direct messaging, reactions, and community discussions are outside this checkpoint.
